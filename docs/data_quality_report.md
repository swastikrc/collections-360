## How issues are handled

- **Raw zone** keeps every file exactly as delivered (all text), so nothing is lost on load.
- **Curated zone** keeps every row and every original column. Fixes are added as new columns (`*_std`, `*_recomputed`, `dq_*` flags), so both the stored value and the corrected value are visible.
- **Golden zone (C360, MongoDB)** uses the corrected values, and lists each customer's data quality notes on their document.
- Nothing is deleted. Records that can't be linked confidently go to a human review queue.
